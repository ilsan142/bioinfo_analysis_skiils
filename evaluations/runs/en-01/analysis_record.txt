합성 marker panel의 treated-control 탐색 분석 (2026-10-17)

결론: marker_A의 treated-control 차이는 +1.025 log2 intensity 단위이고,
배치별 분석과 donor 한 명씩 제외하는 민감도 분석에서도 양의 방향이 유지된다.
marker_B와 marker_C의 차이는 각각 +0.100, -0.100이나 신뢰구간이 0을 포함한다.
이 결과는 합성 입력의 패턴이며 실제 생물학적 효과나 기전을 입증하지 않는다.

입력과 확인된 설계:
- TASK.md, context.md, metadata.tsv, measurements.tsv만 분석 입력으로 사용했다.
  context.md에 따르면 사람 유래 배양 세포를 흉내 낸 동일 시점 24시간 자료이며,
  값은 배경 보정과 표본 간 정규화가 끝난 log2 intensity다. 0은 유효 척도값,
  NA는 결측이다. 실제 결측과 비유한값은 없었다. 가상 marker라 외부 annotation은 없다.
- sample_id로 연결했다. 측정 열의 원래 순서 S05,S01,S07,S03,S08,S02,S06,S04를
  메타데이터 순서 S01~S08에 맞췄다. 중복·누락·불일치 ID는 0개다.
- 3 markers × 8 samples이며 8개 donor_id가 모두 고유하다. 독립 단위는 donor,
  control 4명, treated 4명이다. 기술 반복·짝지음은 없다.
- 각 조건에 배치 A/B가 2명씩 있다. 조건과 배치의 완전 교락은 없으며
  절편+treated+batch_B 설계행렬 계수는 3/3이다.
- 추가 로그변환, 정규화, 결측 대치, 집계, marker 필터링, 표본 제외를 하지 않았다.
  입력과 분석 모두 3 markers × 8 samples다. 사전 제외 기준인 측정 실패 기록이 없다.

실제 진행과 선택 근거:
1. python analyze.py qc를 먼저 실행하고 ID, 독립 반복, 배치 교차표와 분포를 읽었다.
   marker별 control/treated 평균은 A 7.025/8.050, B 5.025/5.125, C 9.025/8.925다.
   조건 내 범위는 A 6.8~7.2/7.9~8.2, B 4.8~5.2/4.9~5.3,
   C 8.8~9.2/8.7~9.1이다. 조건 내 표준편차와 표본별 범위는 run.log에 있다.
   서로 다른 marker 3개의 표본별 분포만으로 실패 표본을 판정하지 않았다.
2. 설계를 확인한 뒤 python analyze.py fit를 실행했다. 이미 log2 척도이므로
   marker별 OLS 선형모형 intensity ~ intercept + treated + batch_B를 사용했다.
   참조는 control과 batch A이며 관심 계수는 treated-control이다.
   잔차 자유도는 5, 95% 신뢰구간은 고전적인 t 기반 구간이다.
   제공된 marker 3개 각각의 양측 조건 비교를 하나의 검정 집합으로 BH 보정했다.
   균형 설계여서 보정 효과 추정치는 단순 평균차와 같다.

marker     차이(log2)    95% 신뢰구간           p             BH q
marker_A   +1.025        [0.87023, 1.17977]     1.27948e-05   3.83843e-05
marker_B   +0.100        [-0.08177, 0.28177]    0.216437      0.216437
marker_C   -0.100        [-0.28177, 0.08177]    0.216437      0.216437

3. 모형 결과를 읽은 뒤 필요한 다음 점검으로 배치별 차이, 잔차, donor 영향도를
   추가하여 python analyze.py all을 실행했다. 이 민감도 분석은 사후 탐색이다.
   배치 B-A 추정치는 A +0.225, B/C 각각 +0.250으로 조건 차이와 별도로 존재한다.
   배치 A/B 내 treated-control 차이는 A +1.05/+1.00, B +0.10/+0.10,
   C -0.10/-0.10이다. 이 표본에서 큰 배치별 효과 불일치는 관찰되지 않았다.
   donor 한 명씩 제외해 다시 적합한 차이의 범위는 A 0.98~1.06,
   B 0.06~0.14, C -0.14~-0.06이다. 주분석은 8명을 모두 유지했다.
   최대 절대 내부 표준화 잔차는 A 1.671, B/C 1.265였고,
   최대 Cook 거리 A 0.559는 작은 표본에서 영향도 점검의 필요성을 보여준다.
   실제 재적합 범위상 A의 차이가 특정 donor 한 명에만 의존하지는 않았다.
   숫자 기준으로 표본을 제거하지 않았다.

해석의 한계와 다음 연구 점검:
- 신뢰구간과 p값은 독립적·등분산·대략 정규적인 잔차 및 가산적 배치효과라는
  모형 가정에 의존한다. 독립 donor라는 관계는 context.md에 명시되어 있으나
  8명만으로 잔차 가정이나 상호작용 부재를 확증할 수 없다.
- B/C의 0 포함 구간은 무효과나 동등성을 입증하지 않는다. 검정 결과를 근거로
  marker를 골라 재검정하거나 유리한 제외를 하지 않았다.
- 처리 무작위 배정, donor 특성, 실제 측정 실패/정규화 과정의 원자료는 제공되지
  않았다. 따라서 인과적 처리효과, 무작위화 검정, 원자료 수준 측정 검증은 하지 않았다.
- 합성 자료를 넘어 연구로 확장하려면 배정 기록과 donor 공변량을 확인하여
  잔여 교락을 점검하고, 양 배치에 조건을 교차 배치한 추가 독립 donor에서
  효과크기·분산·배치별 일관성을 검증해야 한다. 현재 코드의 실행 성공이나
  donor 제외 민감도는 그러한 독립적 생물학 검증을 대체하지 않는다.

재실행과 산출물:
- 작업 위치: /tmp/bio-skill-en-01
- 재실행 명령: python analyze.py all
- 코드: analyze.py. 수치 결과 및 민감도: results.tsv. 단계별 명령과 실제 표준출력,
  입력 SHA256, 환경 버전 및 전체 재실행 확인: run.log. 설명 기록: 이 파일.
- Python 3.12.7, NumPy 2.1.3, pandas 2.3.1, SciPy 1.16.0,
  statsmodels 0.14.5를 사용했다. 설치나 외부 자료 다운로드는 하지 않았다.
- 난수 연산은 없어 seed가 필요 없다. 최종 전체 실행을 새 Python 프로세스에서
  반복하여 results.tsv의 바이트 단위 동일성을 확인했다.
- 3 marker의 작은 표가 질문에 충분하여 그림은 만들지 않았다. 그림 시각검토는
  해당 없음이며, 표의 실제 수치와 잔차·donor 제외 결과를 읽어 검토했다.
- 원본 입력은 보존했다. 기록한 분석은 모두 실행했고, 위 추가 연구 검증은 미실행이다.
