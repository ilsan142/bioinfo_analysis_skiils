# 상황별 과학적 검토

현재 판단에 필요한 절만 읽는다. 아래 항목은 적용 조건이 있는 판단 규칙이며, 고정 파이프라인이나 모든 분석의 체크리스트가 아니다. 수치 임계값은 보편값으로 만들지 말고 실험·방법의 근거와 사전 기준을 따른다.

## 입력 의미와 전처리

값의 생성 도구·단계·단위와 기존 처리를 확인한다. 정수 여부는 진단 정보이지 측정 유형의 증명이 아니다. 소수는 정규화값일 수도, 확률적 read 할당의 추정 counts일 수도 있다. 계수 모형을 실행하기 위해 반올림하거나 임의로 원자료를 복원하지 않는다. 추정 counts에는 생성 도구와 분석 방법이 지원하는 import 경로·offset 등을 검토한다. DESeq2 공식 문서는 입력 counts와 transcript quantification 가져오기를 구분한다. [DESeq2 공식 문서](https://bioconductor.org/packages/release/bioc/vignettes/DESeq2/inst/doc/DESeq2.html)

결측은 미측정·검출 한계·기술 실패·필터링 중 무엇인지, 0은 부재·불검출·변환된 기준점 중 무엇인지 확인한다. 모르면 후보 해석을 기록하고 그 해석에 의존하는 대체·검정을 미룬다. 상대량의 변화만으로 절대량 변화나 속도 상수를 확정하지 않는다.

필터·정규화·집계·대체는 답하려는 질문과 연결한다. 처리 전후 표본/feature 수와 바뀐 단위를 남긴다. 표본 제외는 측정 품질·식별 오류·실험 기록·합의한 기준으로 검토한다. 불리한 표본을 제거한 결과만 제시하지 않는다. 영향이 중요한 합리적 대안이 있으면 주 분석을 보존하면서 제한된 민감도 분석을 한다.

## 독립 단위와 모형의 식별 가능성

배정 단위, 채취 단위, 측정 단위를 구분하고 개체→검체→라이브러리/세포/spot 연결을 확인한다. 기술 반복은 자동으로 독립 n이 되지 않는다. 생물학적 비교에 맞는 집계·paired 모형·혼합 모형 등을 선택하되 의존 구조를 모른 채 고르지 않는다. n은 단위와 함께 보고한다.

모형을 쓰기 전 관심 효과를 명시한다. 예: “같은 환자에서 처리 후와 전의 평균 차이”와 “서로 다른 환자 집단의 차이”는 다르다. contrast 방향과 reference level, 공변량, paired/nested 항을 실제 설계 행렬·코드에서 확인한다.

조건×배치 교차표와 설계 행렬의 독립성을 확인한다. 완전 혼동이면 관측된 집단 차이는 보여줄 수 있지만 조건에 고유한 효과로 추정할 수 없다. 항을 삭제하거나 pseudoinverse·통합 알고리즘을 사용해 수치가 나왔다고 분리된 효과가 되지 않는다. 식별 가능한 비교나 조건을 가로지르는 추가 표본이 필요한지 설명한다. DESeq2의 “Model matrix not full rank” 절은 선형 종속과 배치/조건 혼동을 다룬다. [DESeq2 공식 문서](https://bioconductor.org/packages/release/bioc/vignettes/DESeq2/inst/doc/DESeq2.html)

## 효과·불확실성·탐색

가능하면 비교 방향, 효과와 단위, 신뢰구간 또는 정당화된 불확실성 요약, 독립 n을 제시한다. 작은 n에서 정밀도가 낮음을 숨기지 않는다. 검정이 부적절하면 기술 요약과 추론 불가 이유가 더 적절할 수 있다. p값이 없다고 임의로 만들지 않는다.

다중검정에서는 어떤 feature/contrast를 한 검정군으로 보았는지, 어떤 보정을 했는지 기록한다. 선택 후 검정, 반복 탐색, 결과를 본 뒤 임계값 변경은 불확실성 해석에 영향을 준다. 비유의성은 효과 없음의 증명이 아니며, 무효과나 동등성을 주장하려면 그 질문에 맞는 설계·정밀도·기준이 필요하다.

분석 시작 때 정한 선택과 사후 변경을 분리한다. 변경 이유가 오류 수정인지, 새 실험 정보인지, 탐색적 가설인지 표시한다. 관측→후보 설명→추가 검증의 단계를 유지한다. enrichment는 배경 집합, ID 매핑·중복, 유전자 선택 과정에 따라 달라진다. 결과를 기전 증명으로 승격하지 않는다.

## 예측모델

새 개체·기관·연구·시점·서열군 중 어디로 일반화할지 정한다. 해당 단위가 겹치는지 split manifest에서 점검한다. 미래 예측에는 시간 순서, 관련 서열에는 상동성/유사성 군집 등 문제에 맞는 분리를 검토한다. 무조건 무작위 행 분할하지 않는다.

학습되는 imputation·scaling·특징 선택·차원 축소는 각 훈련 fold 안에서 fit한다. 검증 fold는 transform과 평가에만 쓴다. 튜닝과 모델 선택에는 훈련 측 내부 검증을 쓰고 최종 holdout은 반복 선택에 재사용하지 않는다. 전체 자료로 고른 특징은 분할만 다시 해도 누수가 남으므로 원래 특징부터 재구성한다. scikit-learn은 feature selection을 포함한 누수 사례와 Pipeline을 통한 분리를 설명한다. [공식 common pitfalls](https://scikit-learn.org/stable/common_pitfalls.html)

일반화 단위에 맞는 분할·대조 모형·성능 지표·불확실성을 정한다. 성능 개선은 그 평가 범위의 예측 근거이며 기전이나 임상 유용성의 검증과 다르다.

## 데이터 유형에 따라 필요한 추가 확인

| 적용 상황 | 먼저 확인할 구체적 문제 | 넘지 말아야 할 해석 경계 |
| --- | --- | --- |
| Bulk RNA-seq | count 생성/추정 경로, 기존 정규화, 조성·library 크기, annotation, 비교 설계 | TPM·로그값을 raw counts처럼 사용하지 않는다. 발현량을 분해율·번역량으로 동일시하지 않는다. |
| Single-cell | donor와 세포 연결, donor별 조건·세포 유형 수, QC·doublet 근거, 원 counts와 통합 embedding 구분 | 세포 수를 독립 donor 수로 세지 않는다. pseudobulk/혼합 모형을 설계와 입력에 맞춰 검토하며, 많은 세포가 부족한 donor 반복을 대체하지 못한다. |
| Spatial | donor→절편→spot/cell 계층, 좌표·해상도, 인접 의존성과 조직 구성 | 인접 spot을 독립 생물학적 반복으로 취급하거나 공간 공존을 상호작용 증명으로 해석하지 않는다. |
| 유전체 변이 | genome build, REF/ALT·strand, sample/ploidy, coverage·callability, genotype QC, ancestry/kinship | 미호출을 reference allele로 바꾸지 않는다. annotation의 병원성 후보를 검증된 기능으로 부르지 않는다. |
| 미생물군집 | count/상대량 구분, 오염·음성 대조, sampling depth, 조성, 반복 채취, taxonomic reference | 비율 증가를 절대 균량 증가로 단정하지 않는다. 0을 모두 부재로 해석하지 않는다. |
| 생물학적 예측 | 목적 population, split 단위, 특징 선택·전처리의 fit 범위, label 생성과 측정 과정 | label 누수나 연구/기관 구별 성능을 목표 생물학적 예측 능력으로 바꾸어 말하지 않는다. |

동일 개체의 세포 의존성은 pseudoreplication을 일으킬 수 있다. 해결책은 설계·목표에 맞춰 선택하며 특정 모형을 모든 single-cell 분석의 정답으로 만들지 않는다. [Zimmerman et al., 2021, 원논문](https://www.nature.com/articles/s41467-021-21038-1)

## Annotation과 주장 근거

ID의 종·참조 버전·namespace를 확인하고 입력 수, 매핑 성공/실패, 일대다·다대일 관계, 처리 원칙을 기록한다. 편리한 symbol 하나로 조용히 합치지 않는다. 조직·세포 구성·시간·종 차이·측정 편향이 해석을 바꿀지 검토한다.

문헌은 실제 열어 확인한 공식 문서나 원논문만 근거로 사용한다. 해당 주장과 링크·버전/확인일을 연결하고, 문헌 사실과 현재 자료의 관측·해석을 구분한다. 접근하지 못했으면 미확인으로 남긴다.

위 링크는 2026-10-17에 확인한 좁은 근거다. 표의 나머지 항목은 이 스킬의 검토 규칙이며 모든 도메인 방법을 검증한 문헌 총설이 아니다. 실제 분석의 구체적 방법·생물학적 주장은 해당 조건에 맞는 출처를 추가 확인한다.
