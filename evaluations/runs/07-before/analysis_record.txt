질문: 합성 bulk marker panel에서 표본 연결과 treated-control 차이 및 현재 설계에 맞는 불확실성.
상태: 제공된 원본 metadata.tsv/context.md에 따른 독립 기증자 분석 완료.

입력·의미
- TASK.md, context.md, metadata.tsv, measurements.tsv만 분석 입력으로 사용했다.
- 적용 스킬: bioinformatics-research-assistant/SKILL.md. 관련 검토/기록 참고 문서도 읽었다.
- 값은 이미 배경 보정·표본 간 정규화한 log2 intensity다. 추가 로그 변환, 반올림,
  count 모형, 결측 대체, feature annotation은 수행하지 않았다.
- 행은 가상 marker 3개, 열은 24시간 표본 8개다. 원본 파일은 수정하지 않았다.

질문 1: 표본 연결과 독립 단위
- 실제 실행: python analyze.py audit > audit_run.log
- sample_id 중복 및 미연결 0; metadata와 측정 열 순서가 다르므로 ID로 연결했다.
  측정 순서: S05,S01,S07,S03,S08,S02,S06,S04.
- 현재 metadata상 D01-D08은 서로 다른 독립 기증자다. 각 donor는 한 번 관측되었고
  기술 반복은 없다. control 4명, treated 4명이며 대응 표본 설계가 아니다.
- 각 condition×batch 조합은 2명; batch A/B 모두 두 조건을 포함한다.
- 결측 0, 값 0은 0개, 유한 값 범위 4.8-9.2. 전후 8개 표본·3개 marker 유지.
- 이 결과를 본 뒤 배치 보정 선형모형을 선택했다. 값의 차이에 따라 표본을 제외하지 않았다.

질문 2: 관심 차이와 불확실성
- 관심 효과: 배치가 같을 때 서로 다른 기증자 집단의 평균 log2 intensity treated-control 차이.
- 모형: y = intercept + beta_treated * I(treated) + beta_batch * I(batch B) + error.
  기준은 control, batch A. donor는 반복 관측이 없으므로 별도 donor 고정효과를 넣지 않았다.
- 각 marker별 statsmodels OLS를 사용했다. 설계행렬 rank 3/3, 잔차 자유도 5.
  조건과 배치가 균형이어서 보정된 차이는 두 군의 단순 평균 차이와 일치한다.
- 95% CI는 beta ± t(0.975, df=5) × SE이다. 독립·등분산·정규 오차와 배치의 가산적
  효과를 가정한 모형 기반 구간이다. 작은 표본에서 가정은 충분히 검증되지 않는다.
- 별도의 유의성 검정/다중검정 주장은 하지 않았다. 구간은 marker별 95%이며,
  세 marker에 대한 동시 95% 보장이나 다중비교 보정 구간은 아니다.

해석·한계
- 합성 자료에서는 marker_A의 양의 차이가 비교적 분명하고 B/C의 구간은 0을 포함한다.
  B/C의 무효과나 동등성을 입증한 것은 아니다.
- 수치는 정규화된 log2 intensity의 차이이며 RNA 절대량·단백질 기능·인과 효과로 해석하지 않는다.
- 배치 내 기증자가 각 조건 2명뿐이다. 조건×배치 상호작용을 별도로 추정하지 않았고,
  가산적 배치 효과와 오차 가정에 불확실성 계산이 의존한다.
- 처리 무작위 배정 여부는 제공되지 않았다. 관측된 조건 차이와 인과적 처리 효과를 구별한다.
- 독립 기증자 관계는 제공 메타데이터에 근거한다. 값만으로 실제 기증자 관계를 검증할 수 없다.
  donor/표본 관계가 정정되면 표본 수·모형·SE·CI·결과 보고를 재계산해야 한다.
- 실제 생물학적 검증, 외부 문헌/annotation 조회, 실제 연구 자료 분석은 수행하지 않았다.
- 작은 표로 질문에 답할 수 있어 그림은 만들지 않았다. 시각 검토 대상은 없다.
