# 합성 marker 자료의 탐색적 비교

분석 질문은 **독립 기증자에서 treated−control의 평균 log2 intensity 차이**다. 현재 합성 자료에서는 marker_A가 일관되게 높다. marker_B와 marker_C의 평균 차이는 작고, 모형 기반 구간은 0을 포함한다. 이 관측은 실제 생물학적 효과·기전의 검증이 아니다.

## 입력과 연결·설계

- 출처: 같은 디렉터리의 `context.md`, `metadata.tsv`, `measurements.tsv`. 원본을 수정하지 않았다. 입력 SHA-256은 `results/qc.json`에 기록했다.
- 값은 배경 보정·표본 간 정규화가 끝난 **log2 intensity**다. 추가 로그 변환, count 모형, 대체, 필터링은 하지 않았다. 0은 유효한 척도값이고 NA가 결측 표기다. 실제 0·결측은 모두 0개다.
- 측정 열 순서가 메타데이터와 다르므로 `sample_id`로 연결했다. 표본 8개와 marker 3개, 관측 24개가 모두 연결되며 중복·미연결 ID는 없다.
- 기증자는 D01–D08의 독립 8명이다. 조건별 4명이며 기술 반복·paired 관계는 없다. marker 3개를 반복 표본으로 세지 않았다. 처리 전후 모두 8명·3개 marker다. 측정 실패 기록이 없고 제외도 없다.
- 모두 동일한 24시간·배양 조건이다. 조건×배치는 다음과 같고, `1 + treated + batch_B` 설계 행렬의 rank는 3/3이다. 조건 효과와 배치 효과를 분리해서 추정할 수 있는 배치 구성이다.

| 조건 | 배치 A | 배치 B | 독립 기증자 합계 |
|---|---:|---:|---:|
| control | 2 | 2 | 4 |
| treated | 2 | 2 | 4 |

## 실제 분포와 차이

각 목록은 해당 조건의 기증자 4명에서 얻은 정렬된 개별 값이다. 작은 자료이므로 전체 관측을 표로 제시했고 그림은 만들지 않았다.

| marker | control 개별 값 | treated 개별 값 | control 평균 | treated 평균 |
|---|---|---|---:|---:|
| marker_A | 6.8, 7.0, 7.1, 7.2 | 7.9, 8.0, 8.1, 8.2 | 7.025 | 8.050 |
| marker_B | 4.8, 5.0, 5.1, 5.2 | 4.9, 5.1, 5.2, 5.3 | 5.025 | 5.125 |
| marker_C | 8.8, 9.0, 9.1, 9.2 | 8.7, 8.9, 9.0, 9.1 | 9.025 | 8.925 |

marker_A는 두 조건 범위가 겹치지 않는다. B·C는 범위가 겹친다. 조건 내 표준편차는 A control 0.171, A treated 0.129, B·C 각 조건 0.171이다. 독립 기증자가 적어 분포 형태를 확정하거나 이상치 기준을 새로 만들지 않았다.

정규화된 연속 log2 값과 독립 기증자 설계에 맞추어 marker별 선형 모형 `intensity ~ 1 + treated + batch_B`를 적합했다. 기준은 control·배치 A다. 관심 계수는 배치를 고려한 treated−control 평균 차이다. 균형 배치이므로 보정 전후 조건 차이는 같다. 아래 구간은 잔차 자유도 5인 t 분포를 사용한 **marker별 95% 신뢰구간**이다.

| marker | 차이 (log2 단위) | 95% 신뢰구간 | 배치 A 안의 차이 | 배치 B 안의 차이 |
|---|---:|---|---:|---:|
| marker_A | +1.025 | [0.870, 1.180] | +1.050 | +1.000 |
| marker_B | +0.100 | [−0.082, 0.282] | +0.100 | +0.100 |
| marker_C | −0.100 | [−0.282, 0.082] | −0.100 | −0.100 |

배치 B−A 차이는 A +0.225, B·C +0.250이다. 따라서 작은 B·C 조건 차이를 읽을 때 배치를 고려할 이유가 있으며, 이 자료의 균형 배치에서는 조건 차이가 배치 구성 때문에 생긴 것은 아니다. 배치별 조건 차이가 비슷하지만, 각 셀 2명으로 조건×배치 상호작용 부재를 입증할 수는 없다. 잔차 범위는 A −0.1125~0.0875, B·C 약 −0.100~0.100이며 정규성·등분산성 검증으로 해석하지 않는다.

## 관측 후 진행한 다음 점검

큰 A 차이와 작은 표본 수를 확인한 뒤, 특정 기증자 하나가 차이를 좌우하는지 **기증자 1명씩 제외해 같은 모형을 다시 적합**했다. 총 8개 재적합/marker이며 모든 설계의 rank가 3이었다. 이는 사후 탐색적 민감도 분석이고, 주 분석은 8명을 모두 포함한다.

| marker | 1명씩 제외했을 때 차이의 범위 (log2 단위) |
|---|---|
| marker_A | +0.980 ~ +1.060 |
| marker_B | +0.060 ~ +0.140 |
| marker_C | −0.140 ~ −0.060 |

따라서 이 자료에서 차이의 방향은 단일 기증자에 의존하지 않는다. 위 범위는 신뢰구간이 아니며, 같은 자료를 재사용한 점검이므로 독립 검증도 아니다. B·C에서 방향이 유지된다는 사실은 무효과를 배제하는 근거가 아니다.

## 한계와 남은 질문

신뢰구간은 독립·등분산·정규 오차 및 배치와 조건의 가산성을 가정한 소표본 모형에 따른다. 조건당 4명으로 이 가정들을 충분히 검증하기 어렵다. 세 구간은 다중비교 보정 없는 개별 구간이며 동시 95% 보장이나 확증적 유의성 판정에 사용하지 않았다. p값·유의 marker 선정·기전 해석은 수행하지 않았다. B·C의 구간이 0을 포함한다고 효과 없음·동등성을 입증한 것은 아니다.

제공된 입력으로 필요한 ID·반복·배치·개별 분포·배치 내 비교·단일 기증자 영향 점검을 실제 완료했다. 무거운 환경 설치·외부 annotation·추가 데이터 조회는 하지 않았다. 실제 연구로 옮긴다면 처리 배정의 무작위화·정규화 및 실패 기준의 근거를 확인하고, 사전 정의한 효과 크기와 정밀도 목표에 맞춘 독립 기증자로 재검증해야 한다. 이 파일에 없는 실험 정보를 추정하거나 생물학적 검증이 완료됐다고 할 수 없다.

## 실행과 산출물

실행 환경: Python 3.12.7, NumPy 2.1.3, SciPy 1.16.0, statsmodels 0.14.5. 설치 없이 기존 패키지를 사용했다. 난수 연산이 없어 seed는 필요 없다.

실제 작업 순서는 다음과 같다. 각 단계의 출력을 읽은 뒤 다음 함수를 추가했고, `analysis.log`는 이 세 번의 stdout/stderr를 순서대로 보존한다.

1. ID·설계·분포 함수 작성 후 `python analysis.py > analysis.log 2>&1` 실행.
2. 연결·균형 배치·분포 확인 후 선형 모형과 배치 내 비교 추가, `python analysis.py >> analysis.log 2>&1` 실행.
3. 전체 효과 확인 후 기증자별 영향 점검 추가, `python analysis.py >> analysis.log 2>&1` 실행. 마지막 실행은 새 Python 프로세스에서 최종 코드 전체를 처음부터 실행했으며 정상 종료했다.

다시 실행:

```bash
cd /tmp/bio-skill-eval-01
python analysis.py > rerun.log 2>&1
```

이 명령은 `results/`의 파생 결과를 다시 쓰며 원본 입력은 보존한다.

- `analysis.py`: 전체 재실행 코드와 연결·값·설계 오류 검사.
- `analysis.log`: 실제 세 단계 실행 출력.
- `results/qc.json`: 연결·표본 수·배치·입력 해시.
- `results/distribution.tsv`: 조건별 개별 값·평균·중앙값·SD·범위.
- `results/effects.tsv`: 보정 전후 효과·95% 구간·배치 계수·잔차 SD.
- `results/within_batch.tsv`: 배치별 평균과 차이.
- `results/aligned_observations_residuals.tsv`: ID로 연결한 개별 관측과 적합값·잔차.
- `results/leave_one_donor_out.tsv`: 제외 기증자와 24개 민감도 추정치.

코드 실행과 입력 정합성 검사는 합성 예시의 계산 근거이며 실제 생물학적 타당성 검증과 구분한다.
