결과 파일
- index.html: 민지의 개인 포트폴리오 페이지
- styles.css: 화면 크기별 레이아웃 및 장식 스타일

사용 방법
index.html을 브라우저에서 엽니다. styles.css를 같은 폴더에 유지하세요.
패키지 설치, 서버 실행, 인터넷 연결이 필요하지 않습니다.

실제로 확인한 내용
- Python 표준 라이브러리 HTMLParser로 HTML을 읽었습니다.
- 한국어 언어 선언, 민지 이름 및 '디자이너입니다.' 문구를 확인했습니다.
- h1/h2/h3 제목 순서, 고유 ID 및 모든 내부 앵커 연결을 확인했습니다.
- styles.css 파일 존재 및 CSS 중괄호 개수 일치를 확인했습니다.
- 모바일 미디어 쿼리, 키보드 초점 표시, 동작 줄이기 설정 지원 규칙이 있습니다.
- 외부 URL 참조, 외부 폰트, 스크립트 및 CSS 가져오기가 없습니다.

제한
- 설치된 Chromium, Chrome, Firefox 실행 파일을 찾지 못해 브라우저 렌더링과 실제 화면 크기별 동작은 검증하지 못했습니다.
- 실제 작업 자료가 제공되지 않아 작업 영역은 '준비 중'으로 표시했습니다.
- 본 요청에는 생물정보학 분석이 없어 생물정보학 스킬을 적용하지 않았습니다.
